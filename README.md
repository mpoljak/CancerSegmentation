# Prostate Cancer Segmentation Using Deep Learning

This project focuses on the segmentation of prostate cancer in whole-slide histopathology images (WSI) using a U-Net architecture with a ResNet encoder.

The system is implemented in Python using deep learning libraries. Its performance is evaluated using the Dice coefficient and Intersection over Union (IoU) metrics.

**Objectives:**

* Explore deep learning architectures for medical image analysis.
* Investigate the specific challenges of processing whole-slide images (WSI) in digital pathology.
* Implement a cancer segmentation model using U-Net with a ResNet encoder.
* Evaluate segmentation performance using Dice and IoU metrics.
